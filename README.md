# vfLogin Releases

Este repositório hospeda apenas os instaladores do vfLogin, publicados
automaticamente pelo pipeline de CI do repositório principal (privado).

Nenhum código-fonte fica aqui — só os assets de cada release (`.exe` do
instalador para Windows).

Baixe a versão mais recente em: [Releases](https://github.com/Frasson7/vflogin-releases/releases/latest)
